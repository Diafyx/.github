# Support

## Getting help

- **Something isn't working?** Check the repository's README first, then search the existing issues. If nothing matches, open an issue using the bug report form.
- **Have an idea or a feature request?** Open an issue using the feature request form.
- **Found a security vulnerability?** Do not open an issue. Follow the [security policy](https://github.com/Diafyx/.github/blob/main/SECURITY.md).

## Response times

Diafyx is a small, independent studio. Issues are read and triaged, but responses can take a few days. Clear, reproducible reports get answered fastest.
